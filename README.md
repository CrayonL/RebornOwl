## ✨ 功能

| 功能 | 行为与当前验证范围 |
| --- | --- |
| 🦉 悬浮入口 | 可拖动的猫头鹰图标，点击打开贴边设置；参数在对应开关下方展开。图标、面板与位置保存已实机检查。 |
| 💎 会员档位 | Super / Super Max 客户端档位切换，提示随最新点击替换旧提示。Max 涉及 AI 入口；**不解除服务端订阅与 AI 权限校验**。 |
| ⚡ 直接通关 | 设置宿主的课程长度参数，由宿主自身结束、结算。仅一节已完成的普通英语复习课经过实机验证；不保证新课、故事、音乐、数学等类型。 |
| 📅 日期 | 独立开关，紧凑日历选择今天或过去日期，禁止未来日期；显示 `yyyy/MM/dd`。地区关闭时按手机当前时区计算，无需切换地区即可选择昨天；只改宿主时钟，不改手机系统时间。 |
| 🌏 地区 | 独立开关，按国家／城市选择时区，默认中国上海，选择即保存；关闭后使用手机当前时区。单开地区不偏移时间戳，不修改 IP、GPS 或账号国家。两项同时开启时，日期按所选地区计算。 |
| ⏱️ 无限时间 | 修改宿主相关计时状态。目标契约已核对，所有计时题型尚未逐一实测。 |
| ✅ 强制正确 | 适配当前判题模型的正确率与正确字段。单元测试和目标契约通过，所有题型尚未逐一实测。 |
| 🎵 音乐课程解锁 | 尝试修复歌曲入口与练习内权限不一致的问题；目标契约与离线回归通过，未使用尚未解锁音乐的账号实测，不保证服务端授权生效。 |
| 🛠️ 调试模式 | 开放宿主调试菜单入口及部分中文标签；各调试项未逐一验收。 |
| 🔓 解锁关卡 | 为新版路径节点、点击弹层和课程会话生成可学习副本，不改写原始路径、已学次数或当前定位。已实测进入后续第 72 部分的普通英语题目页并退出，未答题或结算；开启/关闭重启均停留在原第 71 部分当前关卡，关闭后后续关卡恢复锁定。其他课程类型和服务端结算未验证。 |
| 🔄 重启 | 关闭与重启使用宿主原生按钮，按压时彼此独立；右下角重启提交宿主启动任务后结束旧进程，重新加载配置。建议在课程外操作，未提交进度可能丢失。 |
| 🏠 桌面入口 | 模块独立设置页，可关闭桌面图标；隐藏后可在 LSPosed 中打开模块设置恢复。 |
| 🔗 开源入口 | 显示 GitHub 项目，优先打开已安装的 GitHub App，否则使用网页。 |

开关、会员档位、日期和地区更改后，需要点击面板中的 **重启** 才会重新安装对应 Hook。Toast 表示选择了模块档位，不等于服务端已开通订阅。历史日期是否被服务端接受、补签及连胜修复均未验证。
