# 🦉 重生猫头鹰 · RebornOwl

## ✨ 功能

下表的课程实测为历史记录；本次 6.104.5-china 未提交课程或改变学习进度。

| 功能 | 行为与当前验证范围 |
| --- | --- |
| 🦉 悬浮入口 | 可拖动的猫头鹰图标，点击打开贴边设置；参数在对应开关下方展开。图标、面板与位置保存已实机检查。**默认只开「会员解锁」和「无限时间」，其余开关默认关闭。** |
| 💎 会员解锁 | 打开即按 **Super Max** 生效（客户端把订阅等级写成 GOLD 并置 hasMax），不再有 Super/Max 二选一。**不解除服务端订阅与 AI 权限校验**，Max 专属的 AI 功能仍会被服务端拒绝。 |
| 🚀 经验加成 | 打开即按 **3 倍** 生效（写进真实课程的加成判定与结算字段），不再有 2 倍/3 倍二选一；需要换回 2 倍可改配置项 `xpboost_multiplier`。改动后需点「重启」生效。倍率是对**基础经验**做乘法，基础经验为 0 时结果仍是 0（见下方「直接通关」）。 |
| ⚡ 直接通关 | 把宿主的课程长度设为 **0 道题**，由宿主自身结束、结算。⚠️ 0 道题的会话基础经验为 0，**结算恒为 0 经验**，倍率再乘也是 0；要拿经验请关闭本项或正常做题。仅一节已完成的普通英语复习课经过实机验证；不保证新课、故事、音乐、数学等类型。 |
| 📅 日期 | 独立开关，紧凑日历选择今天或过去日期，禁止未来日期；显示 `yyyy/MM/dd`。地区关闭时按手机当前时区计算，无需切换地区即可选择昨天；只改宿主时钟，不改手机系统时间。 |
| 🌏 地区 | 独立开关，按国家／城市选择时区，默认中国上海，选择即保存；关闭后使用手机当前时区。单开地区不偏移时间戳，不修改 IP、GPS 或账号国家。两项同时开启时，日期按所选地区计算。 |
| ⏱️ 无限时间 | 修改宿主相关计时状态。目标契约已核对，所有计时题型尚未逐一实测。 |
| ✅ 强制正确 | 适配当前判题模型的正确率与正确字段。单元测试和目标契约通过，所有题型尚未逐一实测。 |
| 🛠️ 调试模式 | 隐藏功能：**面板里没有这一行**，始终启用。入口是标题右侧猫头鹰图标上**快速连点三次以上**，直接打开宿主官方调试菜单（连点第四下不会重复打开）。同时让 release 包不再被判为「无资格」而立刻退出，并汉化部分条目。各调试项未逐一验收。 |
| 🔓 解锁关卡 | 为新版路径节点、点击弹层和课程会话生成可学习副本，不改写原始路径、已学次数或当前定位。已实测进入后续第 72 部分的普通英语题目页并退出，未答题或结算；开启/关闭重启均停留在原第 71 部分当前关卡，关闭后后续关卡恢复锁定。其他课程类型和服务端结算未验证。 |
| 🔄 重启 | 关闭与重启使用宿主原生按钮，按压时彼此独立；右下角重启提交宿主启动任务后结束旧进程，重新加载配置。建议在课程外操作，未提交进度可能丢失。 |
| 🏠 桌面入口 | 模块独立设置页，可关闭桌面图标；隐藏后可在 LSPosed 中打开模块设置恢复。 |
| 🔗 开源 | 显示 GitHub 项目入口（模块设置页），优先使用 GitHub App，否则使用网页。**日常面板不再有反馈按钮**：只有第一次检测到功能异常时的弹窗提供「反馈」，平时能用就不打扰。 |

开关改动会**立即写入配置文件，下次启动沿用用户的选择**（内部配置为权威值，外部镜像只在比内部新时才作为覆盖；镜像不可写时会被删除，避免把开关回滚）。开关、会员档位、日期和地区更改后，需要点击面板中的 **重启** 才会重新安装对应 Hook。Toast 表示选择了模块档位，不等于服务端已开通订阅。历史日期是否被服务端接受、补签及连胜修复均未验证。

兼容性做法：功能按「语义字符串 + 方法签名 + 字段语义」定位，**类名只是线索**，混淆名变了不需要改代码；但结构或语义真的变了（字段换类型、公式改写等）会显式失败并写进模块日志。用户只看到一句话：「部分功能暂时不可用」+ 具体是哪些功能，**不显示类名、签名或异常栈**；没开启的功能即使结构异常也不会弹窗打扰。
