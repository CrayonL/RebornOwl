# 🦉 重生猫头鹰 · RebornOwl

面向多邻国的 LSPosed 模块：会员档位、经验加成、日期与地区、限时、判题、关卡和调试入口都在客户端侧处理，不改服务端订阅，也不改手机系统设置。

## 📦 安装

1. 手机需要装好 LSPosed（或兼容的 Xposed 实现）；模块在清单里静态声明了作用域 `com.duolingo`，装上后在 LSPosed 里启用即可。
2. 安装本模块（`minSdk 26`，Android 8.0 及以上），重新打开多邻国。宿主界面右侧会出现可拖动的猫头鹰，点它打开贴边设置面板；默认只开「会员解锁」和「无限时间」，其余开关默认关闭。
3. 改完开关点面板右下角的「重启」，让多邻国按新配置重新加载；这里只重启宿主进程，不动手机时间。
4. 调试菜单不在面板里：在标题右侧猫头鹰图标上快速连点三次以上，打开宿主调试菜单。
5. 模块自己的设置页可从桌面图标或 LSPosed 的模块设置进入。

## ✨ 功能

🦉 悬浮入口 · 💎 会员解锁 · 🚀 经验加成 · ⚡ 直接通关 · 📅 日期 · 🌏 地区 · ⏱️ 无限时间 · ✅ 强制正确 · 🛠️ 调试模式 · 🔓 解锁关卡 · 🔄 重启

开关改动会立即保存，下次启动沿用；日期／地区参数不合法时（例如配置里残留未来日期）开关会回滚，并用 Toast 说明原因。

## ⚠️ 已知限制

最近一轮在多邻国 6.106.5（2503）上完成重新构建、覆盖安装与功能加载检查，未答题、未提交课程或进度。以下为当前实现下仍然存在的边界。

- **直接通关拿不到经验**：课程长度被设为 0 题，会话基础经验为 0，倍率再乘也是 0。
- **会员只在客户端**：服务端订阅、AI 和 Max 专享权限不变；由宿主自己判断的视频通话等入口仍可能不可用。
- **经验倍率是否被服务端采信未验证**：只确认界面预览与上送字段一致，没有抓包对比结算结果。
- **调试菜单**：准入判定已放行，但菜单里的调试项未逐项验收。
- **日期与地区**：历史日期是否被服务端接受、补签与连胜修复均未验证。
- **题型覆盖**：计时、判题、解锁关卡只在部分课程类型上实测，其他题型与服务端结算未逐一验证。
