# 🦉 重生猫头鹰 · RebornOwl

面向多邻国的 LSPosed 模块：会员档位、经验加成、日期与地区、限时、判题、关卡和调试入口都在客户端侧处理，不改服务端订阅，也不改手机系统设置。

## 📦 安装

1. 手机需要装好 LSPosed（或兼容的 Xposed 实现）；模块在清单里静态声明了作用域 `com.duolingo`，装上后在 LSPosed 里启用即可。
2. 安装本模块（`minSdk 26`，Android 8.0 及以上），重新打开多邻国。宿主界面右侧会出现可拖动的猫头鹰，点它打开贴边设置面板。
3. 改完开关点面板右下角的「重启」，让多邻国按新配置重新加载；这里只重启宿主进程，不动手机时间。
4. 桌面图标是模块自己的设置页，可以在那里关掉；关掉后从 LSPosed 的模块设置进入。

## ✨ 功能

下表是历史验证记录。最近一轮在多邻国 6.106.5（versionCode 2503）上重新构建、覆盖安装并检查了九项功能的加载状态；没有答题、提交课程或改变学习进度。

| 功能 | 行为与当前验证范围 |
| --- | --- |
| 🦉 悬浮入口 | 宿主内可拖动的猫头鹰图标，点击打开贴边设置，参数在对应开关下方展开，位置会记住。图标、面板与位置保存已实机检查。**默认只开「会员解锁」和「无限时间」，其余开关默认关闭。** |
| 💎 会员解锁 | 打开即按 **Super Max** 生效：客户端把订阅等级写成 `GOLD` 并置 `hasMax`，不再有 Super/Max 二选一。**不解除服务端订阅与 AI 权限校验**，Max 专属的 AI 功能仍会被服务端拒绝。 |
| 🚀 经验加成 | 打开即按 **3 倍** 生效：在「按背包算加成」的那对静态方法上写入倍率，界面经验预览与上送的结算字段（`xpBoostMultiplier` / `hasBoost`）一致跟随，不写库存、不触发领取。要换回 2 倍可改配置项 `xpboost_multiplier`。改动后需点「重启」生效。倍率是对**基础经验**做乘法，基础经验为 0 时结果仍是 0（见下方「直接通关」）。 |
| ⚡ 直接通关 | 把宿主的课程长度设为 **0 道题**，由宿主自身结束、结算。⚠️ 0 道题的会话基础经验为 0，**结算恒为 0 经验**，倍率再乘也是 0；要拿经验请关闭本项或正常做题。仅一节已完成的普通英语复习课经过实机验证；新课、故事、音乐、数学等类型不保证。 |
| 📅 日期 | 独立开关，紧凑日历选择今天或过去日期，禁止未来日期；显示 `yyyy/MM/dd`。地区关闭时按手机当前时区计算，无需切换地区即可选择昨天；只改宿主时钟，不改手机系统时间。 |
| 🌏 地区 | 独立开关，按国家／城市选择时区，默认中国上海，选择即保存；关闭后使用手机当前时区。单开地区不偏移时间戳，不修改 IP、GPS 或账号国家。两项同时开启时，日期按所选地区计算。 |
| ⏱️ 无限时间 | 把限时练习的计时字段改成 **99 分钟**，不改课程长度，也不改其他整数参数。目标契约已核对，各计时题型尚未逐一实测。 |
| ✅ 强制正确 | 只改明确的判题字段：会话的 `alwaysGradeCorrect`、语音得分、段落正确率，以及字符／单词／听力配对判断。单元测试和目标契约通过，各题型尚未逐一实测。 |
| 🛠️ 调试模式 | 隐藏功能：**面板里没有这一行**，始终启用。入口是标题右侧猫头鹰图标上**快速连点三次以上**，直接打开宿主官方调试菜单（第四下不会重复打开）。同时放行 release 包的准入判定（不再记 `Ineligible user accessed the debug menu` 后立刻关闭），并汉化部分条目。各调试项未逐一验收。 |
| 🔓 解锁关卡 | 为路径节点、点击弹层和课程会话生成可学习副本，不改写原始路径、已学次数或当前定位。实测可进入后续普通英语题目页并退出，未答题、未结算；开启／关闭重启后当前关卡不变，关闭后后续关卡恢复锁定。其他课程类型与服务端结算未验证。 |
| 🔄 重启 | 关闭与重启使用宿主原生按钮，按压时彼此独立；右下角「重启」提交宿主启动任务后结束旧进程，按新配置重新加载。建议在课程外操作，未提交的进度可能丢失。 |
| 🏠 桌面入口 | 模块独立设置页，可关闭桌面图标；隐藏后可在 LSPosed 中打开模块设置恢复。 |
| 🔗 开源 | 模块设置页显示 GitHub 项目入口，优先使用 GitHub App，否则使用网页。**日常面板不再有反馈按钮**：只有第一次检测到功能异常时的弹窗提供「反馈」，平时能用就不打扰。 |

开关改动会**立即写入配置文件，下次启动沿用用户的选择**（内部配置为权威值，外部镜像只在比内部新时才作为覆盖；镜像不可写时会被删除，避免把开关回滚）。开关、日期和地区更改后，需要点击面板中的 **重启** 才会重新安装对应 Hook。日期／地区开关在参数不合法时（例如配置里残留了未来日期）会回滚为原状态，并用 Toast 说明原因，不会写入半套配置。

兼容性做法：功能按「语义字符串 + 方法签名 + 字段语义」定位，**类名只是线索**，混淆名变了不需要改代码；但结构或语义真的变了（字段换类型、公式改写等）会显式失败并写进模块日志。用户只看到一句话：「部分功能暂时不可用」+ 具体是哪些功能，**不显示类名、签名或异常栈**；没开启的功能即使结构异常也不会弹窗打扰。

## ⚠️ 已知限制

- **直接通关拿不到经验**：课程长度被设为 0 题，会话基础经验为 0，倍率再乘也是 0。
- **会员只在客户端**：服务端订阅、AI 和 Max 专享权限不变；由宿主自己判断的视频通话等入口仍可能不可用。
- **经验倍率是否被服务端采信未验证**：只确认界面预览与上送字段一致，没有抓包对比结算结果。
- **调试菜单**：准入判定已放行，但菜单里的调试项未逐项验收。
- **日期与地区**：历史日期是否被服务端接受、补签与连胜修复均未验证。
- **题型覆盖**：计时、判题、解锁关卡只在部分课程类型上实测，其他题型与服务端结算未逐一验证。
- **音乐课程解锁已下线**：1.0.7 起不再提供，相关入口与权限改写一并移除。
